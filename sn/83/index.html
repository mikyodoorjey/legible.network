Explained from zero · other · written 2026-09-10

SN83 CliqueAI is a timed puzzle league: solvers get a network of a few hundred dots and a few seconds to find the largest group where every dot touches every other, and the league pays the best solvers.

The commodity, explained from zero

The puzzle is the maximum clique problem. Draw dots, connect some pairs with lines, and find the biggest set of dots in which every pair is connected. The site's headline calls this approximating NP algorithms, problems whose answers are quick to check but slow to find. No application of the problem is named anywhere in the subnet's materials.

So the commodity is a solution to a puzzle the validators themselves wrote. Validators keep a database of graphs with 290 to 700 dots and hand them out with time limits between 6 and 30 seconds. A solution "is a set of vertices". Nobody buys these solutions. For someone to pay, the subnet would need a door for a real graph, a scheduling conflict or a social network, and the materials describe none.

Why it is on Bittensor at all

The materials do not say. The mechanism document's stated aim is internal: "To empower the whole subnet, we consider both performance and diversity." No page says what decentralization changes for this puzzle, or compares the subnet to a solver run on one laptop. The honest answer from the materials is nothing yet. The comparison breaks here: a puzzle league has a sponsor who wants the puzzles solved, and this league's only paying party is the emission, the subnet's share of newly minted TAO.

How the work gets done

Miners (the solvers) run a program that receives a graph and returns a set of dots inside the time limit; a GPU is not required, and the stated minimum is 4 CPU cores and 16 GB of memory. Validators (the judges) check that the answer is a valid clique, then score it on optimality (size relative to the best answer that round), on difficulty (a factor set by graph size), and on diversity (a bonus for an answer no other miner returned). The final score is optimality times one plus difficulty, plus diversity, smoothed into a rating with a half-life of about 69 samples, which sets the weights that direct emission. The site copy says miners are chosen by stake while the mechanism document says each eligible miner is sampled with equal probability; the sources disagree.

How you would know it works

No such artifact exists on the subnet's own site. The MINER SCOREBOARD on the front page still reads "Loading" after five seconds in a browser. The docs link a Weights & Biases table of validator runs, which logs activity but shows no benchmark or comparison.

What is missing

There is no buyer, no price, no product and no support path. The chain contact CliqueAI@toptensor.ai appears nowhere on the site or in the repository, and toptensor.ai does not resolve. The Discord link is a channel in the shared Opentensor server. The site is a blank shell to anything but a browser, with no about page. The miner README is one command with no install steps; the last release, v0.0.13, is dated 2026-04-14, and the repository was last pushed 2026-07-21. The chain shows 232 active miners against 7 validators.
