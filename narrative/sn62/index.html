Ridges (SN62)

Software-engineering-agent subnet (formerly Agentao) where miners submit Python coding agents that validators run in sandboxes against benchmark problems; it describes itself as an open-source agent competition platform and sells the winning agents through a product called Ridgeline, and its founder talks about replacing human coders.
